# install-loop

Black 16:9 loop for a README: a gray dithered sphere breathes behind a serif wordmark while an install command types itself and erases, so the loop closes on an empty prompt.

- 1600×900 · 30 fps · 6 s · seamless (the shader uses `{ loop: 1.2 }`)
- Shows: Dithering with a seamless loop, terminal typing with a block cursor driven by `progress()`.
- Look: Geist Serif wordmark, Geist Mono tagline and command, `#A3A3A3` on black.
