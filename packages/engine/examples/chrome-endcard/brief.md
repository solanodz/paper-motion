# chrome-endcard

7 s 16:9 end card: a liquid-metal (chrome) wordmark is uncovered by a soft diagonal wipe while the metal calms down, then a tagline rises and an install command types in, with low synthesized sound.

- 1920×1080 · 30 fps · 7 s
- Shows: an image shader (LiquidMetal) fed a wordmark drawn on a canvas (`wordmark.js`), a CSS mask wipe, animating a shader param per frame with `layer.set()`, `s.sfx()` cues (whoosh, thud, keys) and `s.sound()`.
- Look: chrome on black, Geist Serif and Geist Mono.
