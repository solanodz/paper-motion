# Code type

Block: code-type (6.4 s), from paper-motion.app. The look, fonts and sound come from `brand/`.

Code writes itself in an editor in the brand's colours; the camera rides the caret close, then the line that matters lights up.

A block is one ready-made moment. Edit `CONFIG` (its words, numbers and format: 16:9, 9:16 or 1:1, the layout recomposes for each); check `npx paper-motion still` at 0.8 and 4.8 s; render.
