# Terminal run

Block: terminal-run (6.2 s), from paper-motion.app. The look, fonts and sound come from `brand/`.

A command types itself, a spinner works, the output streams in with its checks and the file it made lights up.

A block is one ready-made moment. Edit `CONFIG` (its words, numbers and format: 16:9, 9:16 or 1:1, the layout recomposes for each); check `npx paper-motion still` at 0.6 and 1.5 s; render.
