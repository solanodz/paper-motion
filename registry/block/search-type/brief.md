# Search type

Block: search-type (5.6 s), from paper-motion.app. The look, fonts and sound come from `brand/`.

A command palette opens, the query types fast, the list filters live with the matches underlined and the top result is chosen.

A block is one ready-made moment. Edit `CONFIG` (its words, numbers and format: 16:9, 9:16 or 1:1, the layout recomposes for each); check `npx paper-motion still` at 1 and 1.5 s; render.
